# Project context

Обновлено: 2026-08-04.

## Цель

Собрать хакатонный MVP «Итоги года» для Авито: тестовый пользователь выбирает профиль, запускает генерацию, просматривает персональный связный recap и получает объяснимое следующее действие.

## Обязательные ограничения

- Frontend: React 18+ и TypeScript.
- Backend: Go.
- Общий репозиторий, запуск через Docker Compose.
- База данных выбирается и обосновывается командой.
- Нужны README, линтеры обоих контуров и unit-тесты ключевой логики.
- Нельзя раскрывать переписки, точные покупки и данные других пользователей.
- Правила генерации должны быть воспроизводимыми.

## Принятые рабочие решения

- Monorepo: `frontend/`, `backend/`, `docs/`, `context/`.
- API-first: backend отдаёт готовый `Recap`; frontend не рассчитывает бизнес-метрики.
- Версия API: `/api/v1`; карточки — discriminated union по `type`.
- Результат генерации — immutable snapshot с версией алгоритма и hash активности.
- Share-card — отдельная безопасная проекция.
- Git: стабильная `main`, интеграционная `dev`, персональные рабочие ветки с PR в `dev`.

## Документы

- `docs/task.md` — структурированная исходная постановка и Definition of Done.
- `docs/git-workflow.md` — ветки, PR и правила интеграции.
- `context/API_AND_DATA_MODEL.md` — черновик API, endpoint и объектов данных из переданного DOCX.
