# Project context

Обновлено: 2026-08-04.

## Цель

Собрать хакатонный MVP «Итоги года» для Авито: пользователь выбирает профиль, запускает генерацию и просматривает персональный связный recap.

## Обязательные ограничения

- Frontend: React 18+ и TypeScript.
- Backend: Go.
- Общий репозиторий, запуск через Docker Compose.
- Хранилища: PostgreSQL для пользователей и однажды сформированных итогов; ClickHouse для событий активности и продуктовой аналитики.
- Нужны README, линтеры обоих контуров и unit-тесты ключевой логики.
- Нельзя раскрывать переписки, точные покупки и данные других пользователей.
- Правила генерации должны быть воспроизводимыми.

## Принятые рабочие решения

- Monorepo: `frontend/`, `backend/`, `docs/`, `context/`.
- API-first: backend отдаёт готовый `Recap`; frontend не рассчитывает бизнес-метрики.
- Версия API: `/api/v1`; карточки — discriminated union по `type`.
- Результат синхронно генерируется один раз для пары пользователь–год и хранится как immutable snapshot с версией алгоритма и hash активности.
- Share-card — отдельная безопасная проекция.
- ClickHouse используется только для событий активности и продуктовой аналитики. Пользователи и готовые snapshot-проекции находятся в PostgreSQL.
- Git: стабильная `main`, интеграционная `dev`, персональные рабочие ветки с PR в `dev`.
